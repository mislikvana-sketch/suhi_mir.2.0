# SUSHI MIR — сайт + Telegram-сповіщення

## Публікація на Netlify
1. Розпакуйте архів.
2. Перетягніть папку `sushi-mir` на https://app.netlify.com/drop
3. Після розгортання сайт матиме Netlify-адресу.

## Підключення Telegram-бота
### 1. Створіть бота
1. У Telegram відкрийте офіційний акаунт **@BotFather**.
2. Надішліть `/newbot`.
3. Вкажіть назву, наприклад `SUSHI MIR Orders`.
4. Вкажіть username, який закінчується на `bot`.
5. BotFather надішле HTTP API token. Не публікуйте його і не вставляйте в HTML/JS.

### 2. Дізнайтеся Chat ID
1. Відкрийте створеного бота за посиланням, яке дав BotFather, і натисніть **Start** або надішліть `/start`.
2. У браузері відкрийте адресу (підставте свій токен замість `YOUR_TOKEN`):
   `https://api.telegram.org/botYOUR_TOKEN/getUpdates`
3. У відповіді знайдіть `message` → `chat` → `id`. Це ваш Chat ID.
   - Якщо `result` порожній, напишіть боту ще одне повідомлення і оновіть сторінку.
   - Для групи: додайте бота в групу, напишіть у групі повідомлення, тоді в `getUpdates` знайдіть ID групи (зазвичай від’ємне число).

### 3. Додайте секрети в Netlify
1. Відкрийте сайт у Netlify.
2. Перейдіть: **Site configuration → Environment variables** (у деяких інтерфейсах: **Project configuration → Environment variables**).
3. Створіть дві змінні:
   - `TELEGRAM_BOT_TOKEN` — токен від BotFather
   - `TELEGRAM_CHAT_ID` — ваш Chat ID
4. Збережіть змінні та зробіть новий deploy (наприклад, **Deploys → Trigger deploy → Deploy site**).

Після цього кожне успішно оформлене замовлення надсилатиметься у Telegram. Сам сайт не показує токен відвідувачам.

## Важливо
- Не надсилайте токен бота в чат і не додавайте його до файлів сайту.
- Якщо токен випадково став публічним, перевипустіть його через BotFather командою `/revoke`.
- Telegram-бот надсилає повідомлення в особистий чат, тільки якщо користувач спершу натиснув Start, або в групу, де бот має право писати.
- Адмін-панель сайту в цій версії без пароля, а товари зберігаються в localStorage конкретного браузера. Для спільної адмінки всім відвідувачам потрібна база даних та авторизація.
